# Flight

Low-poly survey flight over Mauritius and every named islet within 20 km.

Open it in a browser. Nothing to install.

- [https://flight.mkweli.tech](https://flight.mkweli.tech)
- [https://gilbertbouic.github.io/flight/](https://gilbertbouic.github.io/flight/)

Start the flight, then:

- **W / S** thrust, **A / D** rudder, mouse look
- **Shift** boost
- **F** wireframe, **N** day / night, **R** reset

On a phone, use the thrust stick and the look pad.
