# Flight

Low-poly survey flight over Mauritius and every named islet within 20 km.

**Website:** [https://flight.mkweli.tech](https://flight.mkweli.tech)

## Run

```bash
npm install
npm run dev
```

Start the flight, then:

- **W / S** thrust, **A / D** rudder, mouse look
- **Shift** boost
- **F** wireframe, **N** day / night, **R** reset
